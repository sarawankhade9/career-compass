# CareerCompass — AI Career Guidance Expert System

CareerCompass is an AI-powered career guidance web application designed to help students discover suitable career paths based on their interests, skills, strengths, academic background, and personal preferences.

The website uses an interactive questionnaire and a rule-based expert system to analyse users' responses and recommend relevant career options. It evaluates different traits, identifies strengths and areas for improvement, and ranks careers according to how well they match the user's profile.

CareerCompass provides personalised recommendations, explanations for suggested careers, skill-development guidance, and a visual summary of the user's traits. Users can also view their results, save their progress, print their reports, and export their results for future reference.

Built using HTML, CSS, and JavaScript, CareerCompass offers a simple, user-friendly interface that can be accessed through a web browser. Its goal is to make career exploration easier, more organised, and more accessible for students.

**Objective:** To provide students with an accessible and explainable career guidance tool that supports informed career decisions and helps them explore opportunities aligned with their abilities and interests.

*Note: CareerCompass provides guidance and suggestions, not guaranteed career outcomes or a replacement for professional career counselling.*
